# Project Context

## Goal

Next.js App Router와 FastAPI를 사용해 기존 Todo 기능을 서버 API 기반 풀스택 앱으로 재구현한다.

## Success Criteria

- Todo CRUD, 완료 토글, 날짜별/전체 보기, 필터, 정렬, 페이지네이션, 주간 카운트가 동작한다.
- FastAPI와 SQLite가 Todo 데이터의 source of truth다.
- Next.js Route Handler가 BFF 역할을 한다.
- `localStorage`를 사용하지 않는다.
- README만 보고 실행할 수 있다.
- Agentic AI 개발 하네스가 문서와 Codex 작업 규칙으로 연결되어 있다.

## Out Of Scope

- 사용자 인증
- 배포
- Alembic 마이그레이션
- 다중 사용자 데이터 분리
