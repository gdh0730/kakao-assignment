# ADR-0005: Agentic AI Harness As A Project Artifact

## Status

Accepted

## Context

The assignment should show not only code generation, but an AI-assisted engineering process.

## Decision

Include `AGENTS.md`, `docs/harness/`, ADRs, prompt-log, verification gates, and a repo-scoped Codex skill.

## Why

This turns repeated Codex workflows into reusable project guidance and makes process decisions reviewable.

## Alternatives

- Keep only README notes.
- Use private global Codex settings only.

## Consequences

The repository has more documentation, but the development process is explicit and portable.

## Validation

README explains how the harness is used, and the repo contains the documented files.
