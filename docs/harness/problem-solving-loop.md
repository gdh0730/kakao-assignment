# Problem Solving Loop

1. Symptom: record the exact error, unexpected UI state, or failing test.
2. Reproduction: write the smallest command or user path that reproduces it.
3. Hypotheses: list likely causes.
4. Cheapest Check: test the fastest hypothesis first.
5. Root Cause: name the concrete cause, not just the symptom.
6. Fix Scope: choose the smallest fix that addresses the root cause.
7. Regression Test: add or update a test when the issue can recur.
8. Record: update `prompt-log.md` or `risk-register.md` if useful.
